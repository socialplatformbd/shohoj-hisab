## প্রযুক্তি ও একটি সীমাবদ্ধতা

React 19 + TypeScript + Tailwind CSS 4, IndexedDB (Dexie), Zod, lucide-react, হাতে লেখা Service Worker ও Web App Manifest।
চার্ট হালকা কাস্টম SVG (কোনো চার্ট লাইব্রেরি নেই)।

> **Vite-এর বদলে Next.js:** এই পরিবেশের বেস প্রজেক্ট Next.js (App Router), তাই Vite-এর পরিবর্তে সেটিই ব্যবহার হয়েছে।
> অ্যাপের সব পেজ ক্লায়েন্ট-সাইড; আর্থিক ডেটা শুধু ব্রাউজারের IndexedDB-তে থাকে। সার্ভারে শুধু `/api/ai` (AI প্রক্সি) ও `/api/health` আছে।
> প্রজেক্টের PostgreSQL/Drizzle অংশ অ্যাপের হিসাবে ব্যবহার হয় না (ইচ্ছাকৃত — গোপনীয়তার জন্য)।

## AI কনফিগারেশন

AI সহকারী যেকোনো **OpenAI-সামঞ্জস্যপূর্ণ** `/chat/completions` API-তে চলে। সার্ভারের environment variable-এ দিন (`.env` বা হোস্টিং প্যানেল):

```
AI_API_KEY=sk-...                      # আবশ্যক
AI_BASE_URL=https://api.openai.com/v1  # ঐচ্ছিক (Groq, OpenRouter, Together ইত্যাদিও চলে)
AI_MODEL=gpt-4o-mini                   # ঐচ্ছিক
```
- কী ব্রাউজারে কখনো যায় না; ক্লায়েন্ট শুধু `/api/ai`-তে কল করে।
- `AI_API_KEY` না থাকলে বা অফলাইনে থাকলে অ্যাপ ভেঙে পড়ে না: লেনদেন-এন্ট্রি অ্যাপের নিজস্ব সরল নিয়মে (ফলব্যাক পার্সার) প্রিভিউ দেখায় (স্পষ্ট লেবেলসহ), আর প্রশ্নের জন্য স্থানীয় নির্ধারিত উত্তর দেয়।
- AI **কখনো** ডেটাবেসে লেখে না। AI-র JSON আউটপুট Zod স্কিমায় যাচাই হয়, ব্যবহারকারী প্রিভিউ এডিট ও নিশ্চিত করলে তবেই অ্যাপের কোড সংরক্ষণ করে। সব যোগ-বিয়োগ নির্ধারিত কোডে (paisa পূর্ণসংখ্যা)।
- প্রশ্ন করলে AI-কে অ্যাপ-হিসাব-করা "সারাংশ" (JSON) পাঠানো হয়, কাঁচা লেনদেন নয়। বোতাম চাপার আগে কিছুই যায় না।

## PWA ডিপ্লয়মেন্ট

1. HTTPS-এ ডিপ্লয় করুন (Vercel, Netlify, নিজস্ব সার্ভারে Nginx+Let's Encrypt ইত্যাদি) — Service Worker ও ইনস্টলের জন্য HTTPS দরকার (localhost বাদে)।
2. Node হোস্টিং হলে `npm run build && npm run start`; AI ব্যবহার করলে env ভেরিয়েবল সেট করুন।
3. Android Chrome-এ সাইট খুলুন → মেনু (⋮) → **Install app / হোম স্ক্রিনে যোগ করুন**, অথবা সেটিংসের “অ্যাপ ইনস্টল করুন” বোতাম।
4. একবার অনলাইনে খুললে Service Worker সব পেজ ও JS/CSS ক্যাশ করে; তারপর অফলাইনে চলে।
5. নতুন ভার্সনে ক্যাশ ঝাড়তে `public/sw.js`-এর `VERSION` বাড়ান।
6. আইকন বদলাতে: `node scripts/make-icons.mjs`।

## ব্যাকআপ ও রিস্টোর

- **ব্যাকআপ:** সেটিংস → “ব্যাকআপ তৈরি করুন” → `shohoj-hisab-backup.json`। যেখানে ফাইল-সেভ-পিকার আছে (ডেস্কটপ Chrome) সেখানে লোকেশন বাছা যায়; Android Chrome-এ ফাইল ডাউনলোড হয় (ডাউনলোড ফোল্ডার)। “শেয়ার করে সংরক্ষণ” বোতাম (যেখানে সমর্থিত) দিয়ে Drive/Files-এ সরাসরি রাখা যায়।
- ফাইলে থাকে: লেনদেন, খাত, বাজেট, ধার-দেনা, পরিশোধ, পছন্দ + `version` ও `exportedAt`। ফাইল তৈরি না হলে “ব্যাকআপ হয়েছে” দেখানো হয় না; পিকার বাতিল করলে বলা হয় কোনো ফাইল তৈরি হয়নি।
- **রিস্টোর:** সেটিংস → “ব্যাকআপ থেকে রিস্টোর” → ফাইল বাছুন (Android-এর নিজস্ব ফাইল পিকার)। ফাইল পুরোপুরি যাচাই হয় (স্কিমা, ডুপ্লিকেট আইডি, খাত/ধারের রেফারেন্স, বাড়তি পরিশোধ, নতুন ভার্সন)। নিশ্চিতকরণ ডায়ালগের পর একটি ডেটাবেস ট্রানজ্যাকশনে প্রতিস্থাপন হয় — মাঝপথে ব্যর্থ হলে আগের ডেটা অক্ষত থাকে।
- অন্য ফোনে নিতে: ফাইলটি পাঠিয়ে (WhatsApp/Telegram/USB) সেখানে রিস্টোর করুন।
- ব্রাউজারের সাইট-ডেটা মুছলে বা অ্যাপ আনইনস্টল করলে ডেটা যায় — নিয়মিত ব্যাকআপ নিন।

## ডেটা মডেল সংক্ষেপে

- টাকা সব **paisa (পূর্ণসংখ্যা)**; ইনপুট স্ট্রিং থেকে পার্স হয়, floating-point ব্যবহার হয় না।
- লেনদেনের ধরন: আয়, খরচ, সঞ্চয় জমা, সঞ্চয় তুলেছি। ব্যালেন্স = আয − খরচ − সঞ্চয় জমা + সঞ্চয় তোলা। মোট সঞ্চয় = জমা − তোলা।
- ধার-দেনার "বাকি/অবস্থা" সংরক্ষিত পরিশোধ রেকর্ড থেকে প্রতিবার নতুন করে হিসাব হয় (আলাদা করে জমানো থাকে না, তাই দ্বিগুণ গণনা হয় না) এবং লেনদেনের ব্যালেন্সের সাথে মেশে না।
- তারিখ `YYYY-MM-DD` (Asia/Dhaka); সপ্তাহ শনিবার থেকে।
